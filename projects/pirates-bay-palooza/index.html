Pirates Bay Palooza

A 2D pixel-art pirate shopkeeping game. Public Windows and Android playtests; still in development.

  • Unity
  • C#

Playtest builds

Pirates Bay Palooza is an in-progress 2D pixel-art pirate shopkeeping game. A stranded pirate buys or salvages goods, prices the stock, opens a beach bar to NPC customers, reads the day’s results, and invests before a finite campaign ends.

Public playtest builds for Windows and Android are on GitHub: PiratesBayPalooza-Playtests. They are development builds and can be unfinished. The Unity source is not published.

There is no Steam page and no release date.
