Neon Velocity

A neon arcade racer in the browser. A Unity port for Xbox Series X is in progress.

Browser · Unity

Play in the browser

Neon Velocity is a short-session neon arcade racer. The playable build is in the browser at neonvelocity.mycozy.town. It also sits alongside the smaller toys on mycozy.town, which is a separate arcade site — not this studio page.

A native Unity port aimed at Xbox Series X (and PC) is in progress. There is no store listing yet, and no release date.
